# Pi Miner Gold Rush

Classic Gold Miner reskinned as a **Pi mining** game. Virtual Pi points only.

## Features
- Hand-crank **winch** — miner turns the crank with arms/body/legs synchronized
- **Fatigue & mood system**: mining tires the miner → grumpy → sits on chair → rests → recovers cheerfully
- Level timer **pauses while resting** (no unfair loss of time or coins)
- Expressive faces, speech bubbles, fatigue bar
- 12 progressive stages
- Real BGM + SFX + grunt (mute toggle)
- English ↔ Vietnamese
- SoloHost / Docker ready

## Play
Open `public/index.html` or `npm install && npm start`.

## Controls
- Tap / Click / Space / ↓ → drop hook (ignored while resting)
- 🌐 language · 🔊 mute
